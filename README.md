# Retail Sales Analysis (EDA)

A milestone project on Exploratory Data Analysis.
Developed by: Aden Arshad

## Analysis Pipeline
1. Dataset Loading and Inspection
2. Column Name Normalization and Dtype Casting
3. Duplication Removal
4. Anomaly and Negative Value Fixes
5. Imputation of Missing Values
6. Categorical Standardisation
7. Outlier Identification and Detection
8. Exploratory Analysis and Visualization
9. Executive Interpretation and Management Recommendations

## Tools Used
Python, Pandas, NumPy, Seaborn, Matplotlib
